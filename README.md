## ⚡ Особенности
- 🔍 **Автоматическое распознавание** версий Minecraft (Bedrock, Preview, Education Edition) и популярных клонов / песочниц (Craftsman, LokiCraft, MultiCraft, RealmCraft, PojavLauncher, Master Craft, Survivalcraft и др.).
- 🚀 **Быстрый запуск** выбранной версии в один клик.
- 🎨 **Современный неоновый интерфейс** в стиле Material 3 с отображением имени приложения, версии и типа.
- 📲 **Кнопка "Поделиться"** для быстрой отправки лаунчера друзьям.
